서울캠퍼스 건물 안내

건물 번호 또는 이름으로 검색할 수 있습니다. 카드를 누르면 설명을 볼 수 있습니다.

내용 수정

기본적으로 브라우저 저장을 사용합니다. 여러 사람이 같은 내용을 함께 보려면 아래의 Firebase 설정을 넣어 공동 데이터베이스 모드로 사용할 수 있습니다. (Firebase 웹 SDK 없이도 이 파일 자체는 계속 작동합니다.)

공동 편집 설정

Firebase 연결 확인 중…

Firebase 프로젝트의 Web App 설정값을 입력하면 기관 정보와 리뷰가 여러 사용자에게 실시간으로 공유됩니다. 설정하지 않으면 기존처럼 이 브라우저에만 저장됩니다. 공동 사용을 위해서는 Firebase Authentication의 익명 로그인과 Firestore 보안 규칙 설정이 필요합니다.
